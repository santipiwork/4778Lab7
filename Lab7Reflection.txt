For Lab 7 I learned the implementation of non monobehavior plug ins including a native C++ plug in and a managed C# plug in for Unity and how they are usually faster than mono behavior scripts and especially in massive games are very useful to help the game run better. During the process I learned how to use DlllImport to use the native plug in with C# while the managed C# plug in didn't need any extra addition and could be called as is. Further in the lab I used  System.Diagnostics.Stopwatch to measure the time it took to sort a txt file made using Random.org allowing for fair testing of each method showing that the native C++ plug in was usuall faster than both other while the managed C# plug in and the mono behavior method had very similar results.
